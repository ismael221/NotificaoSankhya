### 📊 **Componente de BI - Notificações (Baseado na Tela Nativa da Aba Mestre Administrador)**

Este componente foi desenvolvido utilizando **SankhyaJS** e **AngularJS**, com o objetivo de replicar e estender a funcionalidade da **tela nativa de notificações** disponível na **aba Mestre Administrador do sistema Sankhya**. A versão em BI permite que os dados sejam exibidos de forma analítica, responsiva e customizável, atendendo às necessidades de monitoramento e gestão em tempo real.

#### ✅ **Funcionalidades Principais**

* Visualização centralizada de **avisos e alertas do sistema**.
* Interface otimizada para BI, permitindo **filtros, agrupamentos e ordenações**.
* Integração com **fontes de dados Sankhya** via componentes SankhyaJS (`sk-application`, `sk-entity-list`, etc).
* Utilização de diretivas e componentes visuais customizados para exibir **status, destinatários, tipos de envio e conteúdo** das notificações.
* Permite **ações rápidas** (edição, remoção, reenvio) com base nos mesmos eventos da tela original.

#### 📦 **Tecnologias Utilizadas**

* AngularJS
* SankhyaJS

#### 🧩 **Casos de Uso**

* Inclusão em dashboards de BI para **acompanhamento gerencial de alertas**.
* Visualização rápida de notificações recentes sem necessidade de acesso à aba Administrador.
* Uso em painéis corporativos para **monitoramento de eventos críticos** ou fluxos automatizados (ex: jobs, rotinas agendadas, falhas de processos).

#### ⚙️ **Diferenciais**

* Reutiliza lógica e regras de negócio da tela nativa, garantindo **consistência funcional**.
* Componentização permite fácil inclusão em outros módulos do sistema.
* Suporte a **customização de filtros** (por período, tipo, prioridade, origem, etc).
